Kho AI Skills của Team là gì?

Nơi lưu trữ 20 kỹ năng AI đã được chuẩn hóa để toàn bộ thành viên sử dụng hàng ngày

Vấn đề: Dùng prompt tự do
• Mỗi người tự viết prompt một kiểu theo cảm tính.
• AI trả lời lúc hay, lúc dở, thường xuyên thiếu các mục quan trọng.
• Mất nhiều thời gian đọc rà soát và chỉnh sửa lại thủ công trước khi nộp việc.
Giải pháp: Kho 20 kỹ năng chuẩn
• Đóng gói sẵn các kỹ năng chuyên môn: viết PRD, tạo PDF in ấn, phân rã WBS, review code...
• Mỗi kỹ năng nằm trong 1 thư mục riêng với file SKILL.md chứa quy trình hướng dẫn cụ thể.
• Toàn team cùng dùng chung một chuẩn mực chất lượng cao nhất.
Tóm lại: Thay vì tự mò mẫm gõ prompt, bạn vào kho này lấy các kỹ năng đã được hoàn thiện sẵn để giao việc cho AI.

Bảo Chứng Độ Tin Cậy

Tem kiểm định chất lượng (Evaluation) là gì?

Cơ chế tự động giúp team phân biệt rõ skill nào đạt chuẩn xịn, skill nào chưa hoàn thiện

1. Barem chuẩn
Mỗi skill có file evaluation.yaml quy định rõ: bài làm đạt phải có những phần nào, lỗi nào bị cấm kỵ, và tiêu chuẩn nghiệm thu là gì.
2. Bộ đôi Benchmarks
Kèm thư mục benchmarks/ chứa tối thiểu 2 bộ đề: tc-01-baseline (nền tảng) và tc-02-realistic (thực chiến), mỗi bài có đủ mẫu Good (Đạt) và Flawed (Lỗi).
3. Dán tem PASS Đạt chuẩn
Khi máy chấm thấy: bài tốt được điểm cao (≥80) và bài làm ẩu bị bắt lỗi rớt → Kỹ năng chính thức được cấp tem PASS để toàn team an tâm dùng.
Vận hành 3 chặng khép kín: AI soạn thảo → Chấm điểm gắn Thẻ Chất Lượng (Quality Scorecard) → Hộp thoại tương tác 1-chạm (Modal UI) ghi nhận phản hồi.

Dành Cho Thành Viên

Quy trình sử dụng & Phản hồi 1-chạm

Trải nghiệm tương tác 3 chặng tiện lợi, chuẩn hóa và không cần gõ lệnh kỹ thuật

1
Ra đề tự nhiên
Chat giao việc như bình thường trong IDE hoặc Web. AI tự động kích hoạt kỹ năng tương ứng từ kho skills/.
2
Nhận bài & Thẻ điểm
Nhận văn bản hoàn chỉnh kèm Thẻ Chất Lượng (Quality Scorecard) hiển thị điểm số 4 chiều và trạng thái PASS/FAIL tức thì.
3
Modal phản hồi 1-chạm
Hộp thoại đồ họa (Modal Popup) tự động hiện ra: bấm chọn 1-click (Rất hài lòng / Cần chỉnh sửa) mà không cần gõ chữ.
Bảo mật tối đa: Phản hồi chỉ lưu metadata điểm số và mã lỗi vào SQLite cục bộ (server/data/eval.db); tuyệt đối không đẩy văn bản dự án ra ngoài.

Dành Cho Người Đóng Góp

Cách đóng góp một kỹ năng mới vào kho

Khi bạn có một prompt hoặc quy trình hay muốn chia sẻ cho đồng nghiệp cùng sử dụng

Bộ hồ sơ bạn cần chuẩn bị
Tạo thư mục mới skills/ten-skill-cua-ban/ với 3 thành phần:

• SKILL.md: Bản hướng dẫn chi tiết quy trình thực hiện.
• evaluation.yaml: Barem tiêu chí (mục bắt buộc, regex cấm, trọng số).
• benchmarks/: Tối thiểu 2 bài test tc-01-baseline.json & tc-02-realistic.json (đều có mẫu Good và Flawed).
Quy chuẩn thẩm định Config-Driven
• Bộ máy chấm điểm động tự nạp evaluation.yaml của bạn để chấm điểm độc lập.
• Chạy kiểm thử cục bộ: npm run eval <tên-skill>.
• Điều kiện nghiệm thu: Cả 2 bài test đều đạt tỷ lệ đối chứng 50% (Good: PASS ≥80, Flawed: FAIL <80).
Nguyên tắc chung: Bất kỳ ai cũng có thể đóng góp skill mới, miễn là trang bị đủ bộ đôi Benchmark để tự động thẩm định chất lượng.

Dành Cho Quản Trị Viên

Cách Repo Owner duyệt đóng góp & Quản trị kho

Kiểm soát chất lượng kho tự động dựa trên số liệu thực chứng định lượng

Cách duyệt một Pull Request
Khi có thành viên gửi kỹ năng mới vào repo:

• Không cần: Ngồi đọc từng dòng hướng dẫn dài dòng để đoán xem nó hay hay dở.
• Chỉ cần: Xem kết quả chạy bài test mẫu tự động npm run eval <skill>.
• Nếu mẫu Good đạt PASS và mẫu Flawed bị FAIL → Bấm Merge (Duyệt) ngay.
Độ phủ 100% & Báo cáo tuần
• Toàn bộ 20 kỹ năng đạt độ phủ kiểm thử 100% với 82 bài test tự động.
• Lệnh npm run report tự trích xuất Top lỗi thường gặp từ server/data/eval.db để quản trị viên sửa đúng câu chữ trong prompt.
Vòng lặp tối ưu: Báo cáo tuần → Bóc tách Top Lỗi → Cập nhật câu chữ trong SKILL.md → Test hồi quy → Phát hành.
Tự động hóa hoàn toàn quy trình kiểm định chất lượng 5 / 6
Phụ Lục Tham Khảo

Bảng tra cứu các câu lệnh kỹ thuật

Dành cho người tạo bài test, Repo Owner hoặc tích hợp kiểm tra tự động trên CI/CD

Câu lệnh Ai sử dụng? Ý nghĩa & Chức năng
npm run eval <tên-skill> Người đóng góp / Dev Chấm thử bài mẫu (tc-01 & tc-02) của 1 kỹ năng theo file barem evaluation.yaml.
npm run eval:all Repo Owner / CI-CD Quét kiểm tra hồi quy 82 bài test trên toàn bộ 20 kỹ năng cùng lúc (offline, an toàn).
npm run eval:all:send CI / Automation Chạy kiểm thử 20 skills và đồng bộ telemetry vào SQLite DB (server/data/eval.db).
npm run server DevOps / Owner Khởi động Ingestion Server & SQLite DB tại cổng 3456 đón nhận telemetry.
npm run report Repo Owner / Sếp Tổng hợp số liệu từ database xuất Báo cáo tuần (Markdown & HTML Dashboard trực quan).
Thành viên lấy skill về dùng không bắt buộc phải chạy các lệnh này. Hệ thống tự động kích hoạt Modal UI để lấy feedback.
